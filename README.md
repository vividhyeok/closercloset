# Closer Closet

날씨에 맞춰 레이어드 코디를 추천하고 직접 입혀볼 수 있는 모바일 우선 웹 애플리케이션입니다. Vite + Vanilla JavaScript로 구현했으며 별도 서버나 API 키 없이 실행됩니다.

```sh
npm install
npm run dev -- --port 5173
```

## 주요 기능

- **초기 설정 및 위치 기반 예보**: 첫 방문 시 캐릭터(남성/여성)와 거주 지역(주요 도시 또는 1회성 현재 위치)을 설정하고 기기에 저장합니다.
- **16일 날씨·코디 룩북**: [Open-Meteo](https://open-meteo.com/) `forecast_days=16`, `past_days=1` 예보를 기반으로 아침·낮·저녁·종일 체감온도별 추천 코디를 제공합니다. 연결 실패 시 6시간 이내 캐시 또는 예시 날씨로 전환됩니다.
- **레이어드 스타일링 스튜디오**: 투명 PNG 스프라이트 조합으로 아우터·상의·하의·신발·모자·머플러·색상을 조합하고, 캐릭터 탭으로 안쪽 겹을 확인하거나 겹 순서를 드래그·키보드로 변경할 수 있습니다.
- **어제 경험 기반 맞춤 보정**: 어제 실제 입은 옷차림과 외출 시간대·체감 피드백(5단계)을 바탕으로 개인 보온 민감도를 보정합니다.
- **내 옷장 & 9:16 공유 카드**: 마음에 드는 코디를 로컬 저장소에 보관·복원·삭제하고, `1080 × 1920` PNG 스토리 카드로 저장하거나 Web Share API로 공유할 수 있습니다.
