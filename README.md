# Closer Closet

모바일 우선 날씨·옷차림 시제품입니다. Vite + JavaScript로 구현했으며 서버나 API 키 없이 실행됩니다.

```sh
npm install
npm run dev -- --port 5173
```

개발 화면: http://localhost:5173/ . CSS 변경은 핫 리로드로, JavaScript 변경은 자동 새로고침으로 반영됩니다. 설정·저장 코디는 브라우저에 남습니다.

## 구현된 흐름

- 첫 방문 캐릭터(남성/여성)와 거주 지역 설정, 기기 저장 후 다음 방문에 설정 생략.
- 현재 위치는 사용자가 요청할 때 `getCurrentPosition`으로 한 번만 확인. 정밀 위치 대신 소수점 둘째 자리까지의 좌표로 예보 조회.
- Open-Meteo의 최대 16일 예보. 가로 날짜 목록, 캐릭터 영역 좌우 스와이프, 키보드 화살표, 날짜 직접 선택, 예보 범위 밖 안내.
- 아침·낮·저녁·하루 종일 체감온도를 기준으로 옷차림 추천.
- AI로 생성한 투명 PNG 스프라이트를 조합하는 옷 입히기. 아우터 7종, 상의 7종, 하의 6종, 신발 3종, 모자 3종(미착용 포함), 색상과 추가 이너 선택.
- 의류 목록은 터치 스와이프와 마우스 가로 드래그로 탐색합니다. 현재는 탭으로 입히기/벗기기를 기본으로 사용하며 키보드 Enter/Space도 같은 동작을 합니다.
- 추움·적당함·더움에 따라 생성된 표정 이미지 변경. 겹수 배지를 호버/탭하면 숨겨진 이너를 포함한 구성 표시.
- 어제 날씨 + 실제 입은 옷 + 외출 시간 + 당시의 느낌으로 보온 추천 개인화. 일반적인 체질 선택 항목은 사용하지 않음.
- 내 코디 기기 저장 및 복원, 삭제. 설정 안 접힌 데이터 관리에서 전체 코디 삭제 / 설정 초기화 구분.
- 1080 × 1920 PNG 코디 카드 생성·다운로드 및 Web Share 파일 공유. 실제로 표시되는 공유 대상은 기기·브라우저·설치된 앱에 따라 다름. 인스타그램에 자동 게시하거나 DM을 직접 보내지는 않음.
- 설치용 웹 앱 매니페스트, 아이콘, 운영 빌드에서 서비스 워커 및 오프라인 앱 화면.

## 날씨와 추천 기준

공식 API: https://open-meteo.com/en/docs . 예보에 `past_days=1`을 포함해 어제의 날씨를 보정에 사용합니다. 날씨 실패 시 최근 6시간 안의 해당 지역 캐시를 표시하거나, 없으면 **예시 날씨**라고 명시합니다. 예시를 실시간 예보로 취급하지 않습니다.

추천은 체감온도와 의류별 상대 보온 점수를 이용한 시제품 규칙이며, 외부 AI 추론을 호출하지 않습니다. 이미지 에셋만 내장 imagegen 도구로 생성했습니다. 사용자의 어제 경험은 제한된 보온 보정값에 반영됩니다. 장기 학습이나 의학적 체온 모델은 아닙니다.

## Vercel

Vercel에서 이 폴더/저장소를 Vite 프로젝트로 가져오면 됩니다.

- Build command: `npm run build`
- Output directory: `dist`
- Environment variables: 없음
- `vercel.json` 포함. 현재 시제품은 로컬 개발 서버로 제공하며 배포는 아직 수행하지 않았습니다.

배포한 HTTPS 주소에서 iPhone Safari의 공유 → 홈 화면에 추가, Android Chrome의 앱 설치/홈 화면에 추가로 실행할 수 있습니다.

## 검증

```sh
npm test
npm run build
```

단위 테스트는 온도별 추천, 체감 피드백, 숨겨진 이너 겹수, 날짜 경계·시간대, 잘못된 API 데이터, 손상된 설정값을 확인합니다. 별도 브라우저에서 첫 방문, 어제 날씨 보정, 실제 예보, 모바일 390px 레이아웃, 포인터 드래그, 저장·재접속, 겹수 안내, PNG 생성·다운로드를 확인했습니다. GPS 권한과 실제 다른 앱으로의 전송은 사용자 기기에서 사용자가 선택합니다.

## 그림 에셋

원본 PNG는 `public/art/`에 보관합니다. 사용한 내장 생성 도구와 프롬프트 브리프는 [docs/image-prompts.md](docs/image-prompts.md)에 있습니다. 렌더러는 `src/doodle-renderer.js`, 현재 파츠별 소스 영역·배치 기준은 `public/art/catalog-front.json`에 있습니다. 의류 파츠는 런타임에 새로 생성되지 않으며, 색상 변형은 브라우저 필터를 사용합니다.

시간대 추천은 `src/daily-look.js`에서 같은 날 같은 기본 의류를 유지하며 외투와 소품을 탈착합니다. 직접 편집 중인 코디는 시간대 변경으로 교체하지 않습니다. 첫 방문 소개 → 설정 → 선택적 어제 경험 보정(5단계) → 추천/편집 → 기기 저장/PNG 공유 흐름입니다.
