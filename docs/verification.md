- 같은 날의 시간대 변경 시 상의/하의/신발 유지 및 외투 탈착, 소재·두께·커버 범위에 따른 보온 차이, 순서 변경의 저장/복원, 후드·밑단 표시를 회귀 테스트에 포함.

실제 iOS/Android 하드웨어에서의 터치·홈 화면 설치와 SNS로 실제 전송하는 단계는 수행하지 않았음. 보온 계산은 상대적 의류 프로필을 사용하는 시제품 추정으로, 실측 clo나 물리 시뮬레이션이 아님. 데이터는 해당 브라우저의 localStorage에 보관되며 계정 간 동기화는 없음.
